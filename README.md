# info2950-project
INFO 2950 (Fall 2026) group project: analyzing chess games from the Lichess and Chess.com APIs.

Group: Kai Harashima (kh862), Skye Moore (sbm232)
- Skye Moore (sbm232): repo set up

## Structure
- `data/raw/` – data as collected from APIs (large files are not committed)
- `data/processed/` – cleaned datasets used for analysis
- `notebooks/` – Jupyter notebooks for exploration and analysis
- `src/` – reusable Python code (data collection, parsing)
- `docs/` – project phase submissions (Phase I brainstorming PDF)
